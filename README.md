# Facebook Marketplace Browser Extensions

A collection of five experimental Chrome/Chromium extensions for Facebook Marketplace workflows. Each extension is kept in its original folder and can be loaded separately as an unpacked extension.

## Extensions

| Extension | Folder | Purpose |
| --- | --- | --- |
| Draft Opener | [`2-20260917T105213Z-1-001/2/`](2-20260917T105213Z-1-001/2/) | Opens Marketplace listing drafts in new tabs. |
| FB Marketplace Auto Location | [`3-20260917T105219Z-1-001/3/`](3-20260917T105219Z-1-001/3/) | Fills in a Marketplace listing location. |
| FB Multi-Tab Location Clicker | [`4-20260917T105233Z-1-001/4/`](4-20260917T105233Z-1-001/4/) | Clicks a location option across open tabs. |
| FB Auto-Publish | [`5-20260917T105237Z-1-001/5/`](5-20260917T105237Z-1-001/5/) | Automates a Marketplace publishing workflow. |
| Facebook Marketplace Autofill | [`i/1/`](i/1/) | Fills listing title, price, description, and images. |

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome or the equivalent extensions page in a Chromium-based browser.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the individual extension folder containing its `manifest.json`.
5. Repeat for any other extension you want to try.

Review each extension's permissions and source code before enabling it. These extensions interact with Facebook Marketplace pages, and changes to Facebook's interface may affect their behavior. This project is an independent collection and is not affiliated with or endorsed by Meta.
